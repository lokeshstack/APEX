AI-Powered Vernacular Pedagogy and Real-Time Translation Tool for Mother Tongue-Based Primary Education

Helping Grade 1–3 teachers adapt English lesson text into the children's mother tongue, so less time goes to translating by hand, with the teacher always in the loop.

Project ID P-2025-29-CD-058-AY26-27Batch 2025–29CD — Cloud and DevOpsStatus: NOT TESTED

Problem and PoC question

PRIMARY USER

Grade 1–3 teacher in a mother-tongue-medium class, preparing daily lessons.

REPORTED PAIN (not measured)

Teachers translate lessons by hand.

THE ONE QUESTION

Can an AI lesson-translation pipeline reach ≥ 85% meaning accuracy vs. teacher translation, within a grade-level readability limit?

NOT BEING PROVED

Full app, speech or live classroom use, rollout, learning-outcome gains.

How it works

One workflow: English lesson text → mother-tongue text, on a small set of Grade 1–3 sentences.

1 · English lesson text
2 · AI translation + adaptation
3 · Mother-tongue text
4 · Teacher review · manual fallback

Safety rule: if any unsafe or misleading output appears, testing pauses and the teacher translates manually.

Limitations

BOUNDARY CASES

Idioms, numbers and mixed-language words are flagged for the teacher, not translated.

THIS DEMO

Lookup of five sentences only. No AI model, speech, accounts or data storage.

UNVERIFIED

Accuracy, curriculum fidelity, speed, classroom use, learning impact, and the translations in four of five languages beyond team knowledge.

DATA

Non-sensitive sample text only. No child data.
